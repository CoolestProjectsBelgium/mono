# @coolestprojects/registration

Nuxt 3 registration SPA. See [docs/apps/registration.md](../../docs/apps/registration.md).

## Quick start

```bash
npm run dev -w @coolestprojects/registration
```

Open https://registration.coolestprojects.localhost:8443

## Scripts

| Script | Description |
|--------|-------------|
| `npm run dev -w @coolestprojects/registration` | Development server |
| `npm run build -w @coolestprojects/registration` | Production build |
| `npm test -w @coolestprojects/registration` | Vitest unit tests |
| `npm run seed:postal-codes -w @coolestprojects/registration` | Regenerate Belgian postal codes JSON |
