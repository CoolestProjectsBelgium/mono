# @coolestprojects/presentation

No web app here. This is a shell-script fleet (`sync-deck.sh` + `slideshow.sh`/`feh-slideshow.sh`/`imv-slideshow.sh`) deployed directly on the Raspberry Pi devices driving Coolest Projects venue displays — it pulls the slide deck from `apps/api`'s `PresentationController` and shows it full-screen.

**Documentation:** [docs/apps/presentation.md](../../docs/apps/presentation.md)
